# Riddhi's Dinner Table

A tiny interactive dinner-table scene. Click the dishes to hear browser-generated, food-matched sound effects. The supplied illustration is used as the actual table artwork; the clickable areas sit over the relevant dishes.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser. If your browser blocks anything, use VS Code's Live Server extension.
3. Click a dish. Turn your computer volume up to a comfortable level; the page starts with sound enabled.

## Publish on Netlify
Drag the whole extracted project folder (the one containing `index.html`, `style.css`, `app.js`, and `assets/`) into Netlify Drop.

Sounds are synthesised locally with the Web Audio API, not prerecorded samples. They are layered to suggest wet noodle slurps, crisp taco bites, soup sipping, glass clinks and fizzy drinks.
